# DominikFau.DataParser

Rozwiązanie zadania kwalifikacyjnego. Proste API (ASP.NET Core Minimal APIs / .NET 8) do odbierania i parsowania danych o różnej strukturze, zakodowanych w standardzie Base64.

## Użyte technologie
- C# / .NET 8
- ASP.NET Core Minimal APIs
- Wbudowane biblioteki do obsługi JSON (`System.Text.Json`)

## Jak uruchomić aplikację lokalnie

1. Upewnij się, że masz zainstalowane środowisko .NET 8 SDK.
2. Sklonuj to repozytorium na swój dysk.
3. Otwórz terminal (wiersz poleceń) i przejdź do głównego folderu projektu (tam, gdzie znajduje się plik `.csproj`).
4. Uruchom aplikację wpisując polecenie:

   ```bash
   dotnet run
